# Student Management and CGPA Dashboard
A Python based student management system built using Streamlit and SQLite.

## Features
- Add Students
- View Students
- Delete Students
- Add subject marks
- Calculate grades
- Calculate SGPA
- Student Performance Dashboard
- SGPA Visualization
- SQLite database

## Technologies Used
- python
- Streanlit
- SQLite
- Pandas
- Git
- Github
